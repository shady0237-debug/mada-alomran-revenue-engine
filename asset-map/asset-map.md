# Asset Map — Mada AlOmran

## Purpose

This file converts the company's known assets into a commercial working map.

The goal is not only to record property information.

For every asset, we want to understand:

**Asset → Status → Target → Value Proposition → Opportunity → Next Action**

This document will be updated whenever the company provides new internal information.

---

# 1. Asset Map Structure

Each asset should eventually contain:

- Asset ID
- Location
- Asset type
- Size
- Building/unit details
- Price
- Current status
- Ownership/control status
- Availability
- Target customer
- Customer problem/need
- Sales angle
- Supporting company services
- Opportunity value
- Current sales stage
- Next action
- Evidence status

**Liquidity × Demand × Margin/Commission × Ease of Reach × Strategic Cross-Sell Potential**

This is a working framework, not a final scoring model.

# 6. Strategic Principle

The Asset Map is not a property catalog.

It is a **revenue map**.

For every asset we eventually want to answer:

**What is it?**

↓

**Who should buy it?**

↓

**Why should they buy it?**

↓

**What is the economic case?**

↓

**How do we reach them?**

↓

**What else can Mada AlOmran sell to them?**

↓

**What is the next action?**
