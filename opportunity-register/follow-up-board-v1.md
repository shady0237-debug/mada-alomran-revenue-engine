# Follow-up Board V1

لوحة بسيطة لمتابعة الفرص المفتوحة وعدم ترك أي فرصة بدون خطوة تالية.

## المتابعة

| Opportunity ID | الفرصة | المرحلة | الخطوة التالية | تاريخ المتابعة | النتيجة |
|---|---|---|---|---|---|
| | | | | | |
| | | | | | |
| | | | | | |

## طريقة الاستخدام

كل فرصة مفتوحة يجب أن يكون لها:
- خطوة تالية واضحة.
- تاريخ متابعة.

بعد المتابعة نحدّث النتيجة ونحدد الخطوة التالية الجديدة إذا كانت الفرصة مستمرة.

## الحالات

- Open — مفتوحة
- Won — كسب
- Lost — خسارة
- Not Qualified — غير مؤهلة

## قاعدة V1

لا نضيف أدوات أو أتمتة الآن.

نستخدم اللوحة يدويًا أولًا، ثم نطوّرها فقط إذا ظهر احتياج حقيقي أثناء العمل.

## المصدر

الفرص تأتي من:
- Opportunity Register V1
- Al-Ruwais Field Sheet V1

هذا إصدار V1 تجريبي وسيتم تحسينه بعد الاستخدام الفعلي.
